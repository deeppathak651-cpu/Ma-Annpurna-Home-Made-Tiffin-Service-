Kumaoni Potli Admin Panel Launcher Fix

This package contains:
- input/admin-panel.html: updated Admin HTML.
- .github/workflows/build-admin-panel-launcher.yml: builds the Admin APK with a native Android PanelLauncher plugin.

Panel package IDs used:
- Customer: com.annapurna.customer
- Restaurant: com.annapurna.restaurant
- Delivery: com.annapurna.delivery
- Admin: com.annapurna.admin

The native launcher opens the separately installed panel APK. The selected panel's own APK is therefore responsible for showing its own Signup/Sign In screen.
