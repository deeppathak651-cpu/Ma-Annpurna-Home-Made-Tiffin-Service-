# Kumaoni Potli Android Project

GitHub steps:
1. Upload this project's files to a GitHub repository.
2. Open Actions.
3. Run **Build Kumaoni Potli APK**.
4. Download the **Kumaoni-Potli-APK** artifact.
5. Install the APK on Android.

App label: Kumaoni Potli
Package: com.kumaonipotli.tiffin

The launcher icon is copied into Android's mipmap resources during the build.
For icon testing, uninstall the previous APK before installing the new one.
